# Island Deathmatch

Open-world **16-player multiplayer deathmatch** on one island — built with Godot 4.7.1 as a
data-driven world (`world.json`) on the Gogi rpg engine template, exported for the web
(single-threaded / WebGL2-compatible, playable in mobile Safari/Chrome/Firefox).

**Play:** https://preview.myapping.com/cloud-z9oviqtefmldofktaojp/index.html
Everyone who opens the same link lands in the same room (up to 16 players). Sign-in
(email + password) is required so peers are identifiable; the session is remembered.

## The island (15×15 cells, ~240 m)
- **Urban core** — a real road grid with ambient traffic, city blocks built from parametric
  structures (concrete + glass, lit window facades, neon sign lights). Four buildings are
  enterable, including the ground-floor lobby of the 80 m hero skyscraper.
- **Farmland** — barns, silos, windmills, water towers and fenced fields, with cows, horses
  and sheep grazing and wandering between them. Arterial roads lead out of the city.
- **Hills** — rolling terrain at the island's edges, falling away into the ocean beyond.

Landmarks (one per zone) for navigation: the glass skyscraper (cyan light), the tower
windmill cluster, and the red-lit steel watchtower on the eastern ridge.

## Gameplay
- One ranged weapon (Scout Rifle) equipped at spawn — auto-aimed, mobile-friendly.
- Other players show on your minimap; frag counter (FRAGS) and DEATHS in the HUD.
- Respawn on death. Day/night cycle (~5 min loop); tower windows glow at night.
- Touch controls (left joystick + drag-look + on-screen buttons) and keyboard/mouse.

## Repo layout
- `world.json` — the entire game as data (cells, structures, weapons, multiplayer, rules, HUD).
  Generated by `gen_world.py` (macro layout) + `merge_gameplay.py` (gameplay layer);
  `architect_notes.md` / `structures.json` document the layout and enterable-interior specs.
- `*.gd`, `project.godot`, `export_presets.cfg` — the shared engine template (Compatibility
  renderer, nothreads web preset).
- `audio/` — CC0 music/SFX/ambient beds.

## Build
```bash
godot --headless --path . --import
godot --headless --path . --export-release "Web" out/index.html
cp world.json quests.json out/ && cp -R models audio out/
```
